# Portfólio Profissional

Portfólio web desenvolvido para apresentar projetos, experiências profissionais, competências técnicas e conhecimentos nas áreas de **Desenvolvimento de Software, Inteligência Artificial, Dados, Infraestrutura e Redes de Computadores**.

O projeto funciona como uma vitrine digital, reunindo em um único ambiente informações sobre trabalhos desenvolvidos, tecnologias utilizadas e áreas de atuação.

## 🎯 Objetivo do Projeto

Disponibilizar uma plataforma web responsiva e de fácil navegação para:

- Apresentar projetos e aplicações desenvolvidas.
- Exibir experiências profissionais e formação acadêmica.
- Organizar conhecimentos técnicos por áreas de especialização.
- Disponibilizar canais de contato e redes profissionais.
- Demonstrar habilidades em desenvolvimento front-end e construção de interfaces web.

## ✨ Funcionalidades

- **Apresentação inicial:** seção de destaque com introdução e navegação.
- **Sobre:** apresentação do perfil profissional e áreas de atuação.
- **Habilidades técnicas:** tecnologias e ferramentas organizadas por categorias.
- **Projetos:** exposição de aplicações e trabalhos desenvolvidos.
- **Experiência profissional:** histórico de atuação e atividades realizadas.
- **Formação acadêmica:** apresentação da trajetória educacional.
- **Contato:** acesso aos canais de comunicação e redes profissionais.
- **Design responsivo:** adaptação da interface para diferentes tamanhos de tela.

## 📌 Execução Local

Para executar o projeto localmente:

```bash
# Clone o repositório
git clone https://github.com/GabrielCDL/portifolio.git

# Acesse a pasta
cd portifolio
```

Em seguida, abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
